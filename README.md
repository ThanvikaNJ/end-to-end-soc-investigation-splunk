 End-to-End SOC Investigation Using Splunk

 Overview

This project demonstrates an end-to-end SOC investigation of simulated SSH brute-force activity in a controlled laboratory environment.

The investigation involved network reconnaissance, authentication log analysis, Splunk SIEM investigation, detection of repeated failed authentication attempts, alert analysis, and incident documentation.
